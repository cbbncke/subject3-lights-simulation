# 灯光通

科目三夜间灯光模拟练习工具，基于公安部《机动车驾驶人考试内容与方法》（GA 1026）灯光模拟考核规则，覆盖 18 类灯光操作指令，支持键盘/鼠标操作、语音播报、连续状态模拟与多套规则管理。

## 在线访问

- 网址：https://dreamy-mousse-92fa20.netlify.app/
- 支持 PWA：手机浏览器打开后，菜单"添加到主屏幕"，桌面生成"灯光通"图标，全屏打开像原生 App
- 离线可用：Service Worker 缓存，首次加载后无网络也能用

## 功能特性

### PWA 可安装

- 手机浏览器打开网址 → 菜单"添加到主屏幕" → 桌面生成应用图标
- 全屏运行，无地址栏，体验接近原生 App
- Service Worker 离线缓存，断网可用

### 三大模式

- **练习模式**：随机出题，操作后点"检查答案"即时反馈对错与原因，可反复练习；支持"重置灯光"一键归零重新操作。
- **模拟考试**：5 题流程，模拟真实考场。
  - 第 1 题固定"请开启前照灯"（开近光）
  - 第 5 题固定"请关闭所有灯光"（全部复位）
  - 中间 3 题从其余 16 题随机抽取，不重复
  - 每题 5 秒限时，超时自动判错并切题
  - **错一题即不合格**（符合考场规则）
  - **灯光状态连续**：前一题灯光延续到下一题，不每题重置（如开近光后，下题"跟车"无需重复操作）；考试结束后自动归零
  - 结束输出成绩单与每题复盘（用户操作日志）
- **规则管理**：支持多套规则切换，预设一套不可改，可新增自定义规则。
  - 预设规则"标准规则（18项）"内置，有语音播报，不可修改/删除
  - 自定义规则存 localStorage，无语音播报，可删除
  - 新增自定义规则：逐条添加指令，操作通过**勾选灯光开关**自由组合（近光/远光/远近交替/示廓灯/双闪/雾灯/左转/右转/全部复位），系统自动拼接 action
  - "基于预设规则填充"：一键复制预设 18 条作为起点，可在此基础上增删改
  - 每条规则支持"查看"展开指令对照表、显示规则项数
  - 自定义规则支持"导出"：弹出预览弹窗，可切换**文本格式**（人类可读编号列表）或 **JSON 格式**（跨平台数据交换），一键复制到剪贴板

### 灯光面板

模拟实车灯光操作，含互斥逻辑（符合实车互锁）：

- 旋钮：OFF → 示廓灯 → 近光 → OFF（循环）
- 远光推/拉操纵杆
- 远近光交替（闪烁，结束必须停在近光）
- 左/右转向灯（开左转自动关右转与双闪，反之亦然）
- 危险报警闪光灯（双闪）
- 雾灯

### 题库（18 条）

开灯类、近光保持类（跟车/路灯/路口/会车/窄路会车）、远近交替类（急弯坡路拱桥/人行横道/无信号灯路口/超车）、远光类（照明不良/变换远光）、停车/故障类（临时停车/故障）、特殊天气（雾天）、转向类（左转/右转）、结束类（关灯）。

### 语音播报

- 预设规则：优先播放本地预录音频（`src/assets/audio/*.mp3`，构建时内联为 base64），播放失败回退浏览器 TTS
- 自定义规则：不播报语音
- **移动端音频解锁**：首次用户手势时用临时 Audio 解锁页面媒体，解决移动端 autoplay 策略限制
- 播报时自动截断上一条，避免重叠
- 音频文件准备见 [AUDIO_GUIDE.md](./AUDIO_GUIDE.md)

### 打赏支持

页面右上角"打赏"按钮，点击弹出微信/支付宝二维码，扫码支持开发者。二维码图片内联到单文件 HTML，双击即可显示。底部含源码获取提示。

### 移动端适配

- 响应式布局（≤768px）：上下布局，灯光面板内部左右分（左状态/右按钮）
- 移动端禁用 hover 粘滞（`@media (hover:hover)` 仅鼠标设备生效）
- mp3 语音内联 base64，移动端稳定播放（不受 TTS 限制）
- 按钮加大，适合手指触摸

## 快速启动

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建产物
npm run preview
```

开发服务器默认地址：http://localhost:5173/

构建产物在 `dist/index.html`（**单文件**，JS/CSS/图片/音频全部内联，约 765KB），可部署到任意静态服务器或**双击直接打开**，无需额外文件。使用 `vite-plugin-singlefile` + `assetsInlineLimit` 实现单文件打包（含 mp3 base64 内联），方便分享给学员离线使用。

## 考试评分规则

- 状态类指令（近光/远光/示廓+双闪等）：检查当前灯光状态是否满足。
- 远近交替类：检查是否有交替动作且结束停在近光。
- 复合操作：按顺序匹配操作步骤。
- 全部复位：检查所有灯光关闭。
